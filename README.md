<h1 align="center">DonewithDan</h1>

Tech VA portfolio focused on GoHighLevel systems, funnels, CRM automation, bookings, follow-ups, and smoother customer journeys.

Built with [Remix](https://remix.run/), [React](https://react.dev/), [Three.js](https://threejs.org/), [Framer Motion](https://www.framer.com/motion/), [Cloudflare Pages](https://pages.cloudflare.com/), and [Formspree](https://formspree.io/).

## Development

```bash
npm install
npm run dev
```

Local URL: http://localhost:7777

Storybook:

```bash
npm run dev:storybook
```

Production build:

```bash
npm run build
```
